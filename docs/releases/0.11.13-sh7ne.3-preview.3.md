## Changes

- Adds a workaround for date/clock clicks not opening Notification Center while
  menu bar icons are hidden on macOS 27. Ice briefly releases its hiding
  assertion, invokes the clock's Accessibility action, then restores the
  current hiding settings. The action has a bounded retry.
- Leaves ordinary app clicks, modifier clicks, drags and long presses untouched.
  No active mouse-event interception, synthesized clicks or idle polling.
- Retains preview 2's system-item visibility controls and settings layout fixes.

## Known Limitations

- Hidden icons can briefly appear while Notification Center is being opened.
  This is a workaround for a private macOS API restriction, not native support.
- Some additional system icons remain unavailable while hiding is active.
  Reveal all sections, disable experimental hiding or quit Ice to restore normal
  system behavior. Another menu bar manager holding an assertion can interfere.
- Ice Bar, divider dragging and several legacy reveal modes remain unavailable
  on macOS 27. macOS 14-26 retain the legacy backend.
- Build, signing, XPC, policy tests and strict lint were checked. The date-click
  workaround still needs broader user testing across display configurations.
